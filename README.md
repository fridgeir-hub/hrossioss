# hrossioss
Útgáfa v3.3.0 er tilbúin í hrossathjalfun.html. Nú geturðu sett hross í geymslu og sótt þau aftur síðar.

Svona virkar þetta:

Að geyma hross: Opnaðu hrossið og ýttu á gráa kassa-hnappinn við hliðina á breyta og eyða. Hrossið hverfur þá af Heim og þú ferð sjálfkrafa aftur á forsíðuna.
Að finna geymd hross: Neðst á Heim birtist „Geymd hross (fjöldi)“ sem þú getur opnað og lokað.
Að sækja hross: Ýttu á „Sækja“ við hrossið og það kemur aftur á Heim.
Þú getur líka opnað geymt hross til að skoða það. Þá stendur efst að það sé í geymslu og þar er líka „Sækja“ hnappur.
Engu er eytt. Öll þjálfun, járningar og myndir fylgja hrossinu, og geymslan fylgir líka með í Export.
